# 🍕 Pizza Sales SQL Analytics Project

### SQL | Data Analysis | Business Insights | Revenue Analytics

---

# 📌 Project Overview

This project is a comprehensive SQL-based analysis of a Pizza Sales dataset designed to generate meaningful business insights from transactional data.

The primary objective of this project was to use SQL to analyze sales performance, customer ordering behavior, product trends, and revenue patterns for a pizza business. The project demonstrates practical problem-solving skills using real-world business scenarios and structured query analysis.

The analysis was divided into three levels:

- **Basic Analysis**
- **Intermediate Analysis**
- **Advanced Analysis**

This structure showcases strong understanding of SQL fundamentals as well as advanced analytical querying techniques.

---

# 📂 Dataset Information

The dataset contains business transaction records related to:

- Orders
- Order Details
- Pizza Types
- Pizza Sizes
- Categories
- Pricing Information
- Revenue Data
- Order Time & Date

The dataset was analyzed using relational database concepts and multi-table joins to uncover valuable business insights.

# 📊 Business Problems Solved

## ✅ Basic Level Analysis

- Retrieved the total number of orders placed
- Calculated total revenue generated from pizza sales
- Identified the highest-priced pizza
- Determined the most commonly ordered pizza size
- Found the top 5 most ordered pizza types

---

## 📈 Intermediate Level Analysis

- Calculated category-wise pizza quantities sold
- Analyzed order distribution by hour of the day
- Determined category distribution of pizzas
- Calculated average pizzas ordered per day
- Identified top 3 pizza types based on revenue

---

## 🚀 Advanced Level Analysis

- Calculated percentage contribution of each pizza category to total revenue
- Performed cumulative revenue analysis over time using window functions
- Generated trend-based insights for business growth evaluation
